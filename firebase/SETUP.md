# Firebase — икки телефон синхронлаш

Ҳозирги Android дастур бронларни фақат телефон хотирасида сақлайди. Бу папка Firebase'ни хавфсиз улаш учун тайёргарлик.

1. https://console.firebase.google.com сайтида Firebase лойиҳа яратинг.
2. Android иловасини `com.aziz.banya` package номи билан рўйхатдан ўтказинг.
3. `google-services.json` файлини Firebase'дан олинг. Уни `app/google-services.json` жойига қўйинг (репозиторийга махфий калитларни қўшманг).
4. Authentication ва Cloud Firestore хизматларини ёқинг. Икки ходим учун аниқ кириш ва рухсат моделини танлаш керак.
5. `firestore.rules` ҳозир барча ўқиш/ёзишни блоклайди. Текширилмаган `allow read, write: if true` қоидасини ишлатманг.
6. Синхрон бронлашда бир хил хона ва вақт учун икки ёзув бир вақтда тушмаслиги Firestore transaction ёки вақт-слотлари бўйича атомар брон билан таъминланиши керак.
7. Офлайн бронни сервер тасдиқламагунча якуний брон сифатида кўрсатмаслик керак.

Кейинги қадам: Firebase лойиҳа конфигурациясини олиш, Authentication ва хавфсизлик қоидаларини ўрнатиш, сўнг Android'га Firestore SDK ва real-time listener улаш.
