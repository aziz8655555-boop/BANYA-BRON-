# БАНЯ БРОН

Android дастури: 6 та хона учун брон қилиш.

## Тасдиқланган талаблар
- Қора-ёғоч фон, тилларанг сарлавҳа
- Асосий экранда 6 хона (2 устунда), яшил «Бўш» ва қизил «Банд»
- «Брон қилиш» тугмаси
- Пастки бўлимлар: «Асосий», «Брон қилиш», «Созламалар»
- Иш вақти: 16:00–23:00
- Тарифлар: 1 соат — 3000 тг; 1,5 соат — 4500 тг; 2 соат — 6000 тг
- Икки телефон ўртасида бронларни синхронлаш режаси
